## 归档文件

- [PRD.md](PRD.md)：早期产品需求与技术决策。
- [ISSUES.md](ISSUES.md)：切片任务、验收标准和执行记录。
- [NOTES.md](NOTES.md)：原型验证记录。
- [ragflow-portal-decisions.md](ragflow-portal-decisions.md)：早期需求决策。
- [ragflow-prototype-handoff.md](ragflow-prototype-handoff.md)：原型交接。

- [HANDOFF.md](HANDOFF.md)：早期工作交接。
- [HANDOFF-phase3.md](HANDOFF-phase3.md)：Phase 3 同源部署修复交接。

## 处理原则

- 归档文件保留原始语境，除非链接迁移或明显路径错误，不做内容重写。
- 新增稳定说明应写到上级当前维护文档，不继续扩充归档文件。
- 需要查某个历史 slice 的验收标准时，优先查 [ISSUES.md](ISSUES.md)。
