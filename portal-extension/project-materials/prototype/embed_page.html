4. 验证要点

  
    
    
  • URL 参数注入:URL 含 ?auth=xxx 时,SSE 请求的 Authorization 应为 Bearer xxx,localStorage 不被读取。
    • 
    
  • postMessage 注入:父页 postMessage 令牌后,embed 页应改用该令牌发 SSE(需覆盖 getAuthorization)。
    • 
    
  • localStorage 绕过:只要 URL 有 auth 参数,localStorage 中是否有旧令牌不影响请求。
    • 
    
  • 网关校验:令牌无效/过期/撤销时,网关返回 401,SSE 不产生流。
